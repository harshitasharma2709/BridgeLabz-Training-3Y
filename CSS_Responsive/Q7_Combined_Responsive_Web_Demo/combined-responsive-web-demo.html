Responsive Design

Responsive design allows a webpage to adapt its layout and content to different screen sizes.

Flexbox, Grid and media queries are important tools for creating responsive websites.

Cheat Sheet

  • Flexbox - One dimensional layout
  • Grid - Two dimensional layout
  • Media Queries - Responsive breakpoints
  • Clamp - Responsive typography
