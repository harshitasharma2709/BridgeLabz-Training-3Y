Responsive CSS Cheat Sheet

Filters

Use CSS filters to change the appearance of images.

filter: grayscale(100%);

Media Queries

Media queries apply CSS based on screen conditions.

@media (max-width: 700px)

Responsive Design

Responsive design makes websites adapt to devices.

width: 100%;

Typography

Responsive typography can use relative units.

font-size: clamp(...);
