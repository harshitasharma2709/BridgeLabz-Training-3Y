Responsive Design Principles

Fluid Layouts

Fluid layouts use flexible sizes so content can adapt to different screen widths. 


.container {
    width: 100%;
    max-width: 1200px;
}

Flexible Media

Flexible images and media resize according to their parent container. 


img {
    max-width: 100%;
    height: auto;
}

Breakpoints

Breakpoints allow different styles to be applied at different screen sizes. 


@media (max-width: 600px) {
    .box {
        width: 100%;
    }
}
